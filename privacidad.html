5. Quién más tiene acceso

Tus datos no se ceden a terceros salvo obligación legal. Para que la web funcione se usan estos proveedores, que actúan como encargados del tratamiento:

  • Google (Google Sheets y Gmail): guarda las solicitudes y envía el aviso de cada solicitud recibida.
  • GitHub (GitHub Pages): aloja la web. Como cualquier servidor, registra datos técnicos como la dirección IP.
  • Google Fonts: sirve la tipografía de la web, por lo que tu navegador se conecta a servidores de Google.

Algunos de estos proveedores pueden tratar datos fuera del Espacio Económico Europeo (Estados Unidos). Esas transferencias se amparan en las garantías que ofrece cada proveedor (Marco de Privacidad de Datos UE‑EE.UU. o cláusulas contractuales tipo de la Comisión Europea).

Si te incorporas a un grupo de WhatsApp de EAS, el resto de integrantes podrá ver tu número de teléfono.
